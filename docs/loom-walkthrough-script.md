# Steer Club — two-minute Loom walkthrough script

**0:00–0:15 — The first note**  
“Steer Club is an anonymous, mobile-first learning experience for metabolic-health questions. The first screen is a doctor’s note rather than an ad: cream paper, rust ink, a dial, and no health score. I’ll lock a first guess.”  
**On screen:** home hero and dial; lock the guess.

**0:15–0:32 — The concern sets the lens**  
“Before the game, the visitor taps the doubt on their mind. That choice shapes exactly two questions and the closing answer. No name, phone number or account is requested.”  
**On screen:** choose “safe”; show the personal note and two selected question IDs in the round.

**0:32–0:58 — One answer, with its source**  
“Each short question turns into a plain-language explanation. Sources are available right here; uncertainty stays visible. The daily puzzle uses five questions, while the other modes use seven.”  
**On screen:** answer a question and open its source drawer; show the stitched progress.

**0:58–1:20 — The Wrapped note**  
“After a round, the Wrapped separates the game score from health. It shows the learning pattern, a missed myth when there is one, a topic takeaway, the original guess and the concern-specific final card. The story PNG is exactly 1080 by 1920.”  
**On screen:** tap through all seven cards; finish on “what matters most for someone like you.”

**1:20–1:42 — A fair friend challenge**  
“A friend gets the same seven questions in the same order, even if they choose a different concern. There’s no leaderboard. When both finish, they can see the comparison and optionally check in on a three-day habit; messages are never sent automatically.”  
**On screen:** show the challenge page and the three daily check-in cards.

**1:42–1:54 — Return without pressure**  
“The daily puzzle, once-a-week grace rule, saved doubt notes and installable offline question shell make it easy to return. Offline mode keeps the local question experience; server saves and sharing need a connection.”  
**On screen:** show the streak and tracker/PWA affordances.

**1:42–1:54 — A careful next step**  
“Care answers stay balanced, and the three-step contact form shows the exact note before explicit consent. The admin view aggregates anonymous events only. The privacy page can delete a browser’s Steer Club server record.”  
**On screen:** open `/care`, show the note preview and consent, then `/admin` and `/privacy` without submitting real contact data.

**1:54–2:00 — Honest boundary**  
“The code is ready for integration, but the new Supabase migration, protected credentials, approved CRM destination and retention policy still need owner sign-off. Vercel and GitHub are not connected in this workspace, and no clinician review is claimed.”  
**On screen:** show `/sources` and its review-status note, then close on the Steer Club wordmark.
